# M4 验收用例（表格、侧边栏与搜索）

SPEC 第 13 章 M4 验收项与对应的自动化测试或手工验证。自动化测试运行
`cargo test -p inkra-ui m4_`、`cargo test -p inkra-engine table`、
`cargo test --release -p inkra-workspace`。

| 验收项 | 自动化 / 手工 | 结果 |
|---|---|---|
| `Ctrl+T` 插入 3x3 表格 | `m4_table_dialog_tab_rows_align_sort`（对话框确认后得到表头 + 分隔行 + 3 行） | 通过 |
| Tab 导航（含末格 Tab 新增行）、`Ctrl+Enter` 新增行 | 同上；`table_editing`、`table_tab_walks_cells_in_order` | 通过 |
| 新增行列、移动、对齐、排序（数字智能比较）、调整大小、复制为 CSV/HTML | `structural_commands_rewrite_aligned_tables`；手工（Linux）：工具条与右键表格菜单 | 通过 |
| 拖拽列宽（仅显示，不写入源码）；拖拽行/列重排 | 手工（Linux Xvfb）：拖动列边界后保存文件不变；拖动行把手、表头上沿把手后源码按新顺序重写 | 通过 |
| 序列化对齐（CJK 宽度 2、保留对齐冒号） | `renders_aligned_with_cjk_width`；`m4_table_…` 断言各行等宽 | 通过 |
| 宽表格水平滚动 | 手工（Linux）：Shift+滚轮与 Tab 跟随光标滚动，滚动条指示 | 通过 |
| 大纲点击跳转（标题置于视口顶部） | `m4_outline_click_jumps_to_heading` | 通过 |
| 文件树拖拽移动文件（打开的文档路径随之更新） | `rename_and_move_follow_open_documents`、`m4_quick_open_and_file_tree_move`；手工（Linux）：拖动 README.md 到 notes 文件夹 | 通过 |
| 文件树 F2 重命名（只选中主文件名）、Delete 移到回收站 | 手工：Linux 重命名；Windows 实机右键删除后文件进入回收站 | 通过 |
| `Ctrl+P` 在 1 万文件中 < 50 ms | `ten_thousand_paths_under_50ms`：1.7～2.1 ms；`m4_quick_open_…` 断言 < 50 ms | 通过 |
| `Ctrl+Shift+F` 首批结果 < 2 s（1 万文件） | `search::perf::ten_thousand_files`：首批 1 ms，全部 40 ms | 通过 |
| 全局搜索点击结果打开文件并进入查找状态 | 手工（Linux）：点击结果打开文件、查找栏填入关键字、高亮匹配 | 通过 |
| 字数统计详情（字数、字符、行、段落、阅读时间、选区统计） | 手工（Linux）：悬停/点击状态栏字数 | 通过 |
| 窗口状态记忆 | 根窗口由 eframe 持久化；其余窗口位置尺寸写入会话并在恢复时还原 | 通过 |

## 已知偏离

- 文章列表与文件树的“创建时间”排序在不报告创建时间的文件系统上退化为无序（取不到时按名称）。
- 侧边栏字号与行高偏好（TH-008，P1）随 M7 偏好窗口提供。
