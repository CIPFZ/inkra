| 验收项 | 方式 | 结果 |
|---|---|---|
| 100 页文档 PDF < 5 s | `inkra-cli convert long100.md long100.pdf`：134 页、121 个书签，0.32 s（Linux Release） | 通过 |
| 书签层级正确 | `exports_a_pdf_with_text_links_and_outline`；PyMuPDF `get_toc()`：`[[1,'Inkra Export Test'],[2,'Math'],[2,'Code'],[2,'Tables']]` | 通过 |
| 文字可选可搜索 | PyMuPDF `get_text()` 与 `search_page_for('中文')` 命中；字体以子集嵌入（Inter、JetBrains Mono、微软雅黑） | 通过 |
| 内部链接可跳转 | `[Tables](#tables)` 与脚注引用生成 GoTo 目标（PyMuPDF `get_links()` 给出目标页） | 通过 |
| 外部链接可点击 | URI 注解 `https://example.com` | 通过 |
| 页眉页脚 | 默认页脚 `{{page}} / {{pages}}`；页面设置对话框修改并保存到偏好（kittest `unimplemented_items_are_disabled_and_about_opens`） | 通过 |
| 分页规则 | `pagination_rules`（整块下移、按行拆分、孤行寡行、标题随后文）；目测：代码块跨页、表格跨页重复表头 | 通过 |
