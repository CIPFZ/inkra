# M3 验收用例（实时渲染 MVP）

SPEC 第 13 章 M3 的验收用例与对应的自动化测试或手工验证记录。自动化测试位于
`crates/inkra-ui/src/tests.rs`（egui_kittest 无头脚本，TS-005），运行
`cargo test -p inkra-ui m3_`。

| # | 用例 | 自动化 | 结果 |
|---|---|---|---|
| 1 | 输入 `# Hello` Enter `World` → H1 与段落；光标回到标题显示淡色 `# ` | `m3_case1_heading_marker_shows_only_in_active_heading` | 通过 |
| 2 | 输入 `**bold** text` → 加粗无星号；光标进入 bold 显示 `**` | `m3_case2_bold_markers_follow_the_caret` | 通过 |
| 3 | `- a` Enter `b` Tab `c` Enter Enter Enter → 嵌套列表后退出为段落，源码正确 | `m3_case3_nested_list_then_paragraph`（源码 `- a\n  - bc\n\npara`） | 通过 |
| 4 | ```` ```rust ```` Enter 粘贴 50 行代码 → 高亮；Down 到末尾再 Down 离开代码块 | `m3_case4_code_block_highlight_and_leaving_with_down` | 通过 |
| 5 | 粘贴截图 → `image-<ts>.png` 写入 `./<doc>.assets/`，源码为相对路径，图片渲染 | 手工（Windows 实机，系统剪贴板位图）；`inkra-workspace::assets` 单测 | 通过：`note.assets/image-20261012203650330.png`，源码 `![](note.assets/image-…png)` |
| 6 | 打开 10 万字文档，滚动 60 fps，输入延迟达标 | `m3_case6_scrolling_a_large_document_is_cheap`、`typing_latency_100k_chars` | 通过：滚动帧 p95 0.14 ms、实时模式输入 p95 3.0 ms（无头 CPU）；Windows 实机源码模式输入 p95 2.36 ms |

| 8 | 外部编辑器修改文件 → 1 s 内刷新 | 手工（Linux Xvfb）：外部写入后 ≤ 1 s 静默重载并保持光标；有本地修改时显示横幅 | 通过 |
| 9 | 关闭未保存窗口 → 三选对话框 | `m3_case9_closing_a_modified_window_asks`；手工（多窗口） | 通过 |
| 10 | 强杀进程后重启 → 恢复对话框列出未保存内容 | 手工（`kill -9` 后重启）：列出文件、时间，可恢复/丢弃 | 通过 |
