# Inkra 快速入门

Inkra 是一个所见即所得的 Markdown 编辑器：你写的是纯文本 Markdown，看到的是排好版的文档。光标移到哪里，那里的 Markdown 标记就显示出来，离开后又隐藏。

## 写作

- 直接输入。`# ` 开头变成标题，`- ` 开头变成列表，`> ` 变成引用，三个反引号开始代码块。
- 选中文字后按 `Ctrl+B` 加粗、`Ctrl+I` 倾斜、`Ctrl+K` 插入链接。
- `Ctrl+T` 插入表格；在表格里 `Tab` 移到下一格，`Enter` 新增一行。
- `$$` 后回车插入公式块；```` ```mermaid ```` 插入图表。
- 粘贴或拖入图片，图片会复制到文档旁的 `assets` 文件夹（可在偏好设置中更改）。
- `Ctrl+/` 在实时渲染视图与源码模式之间切换。

## 文件与文件夹

- `Ctrl+N` 新建窗口，`Ctrl+O` 打开文件，`Ctrl+Shift+O` 打开文件夹（macOS 为快速打开）。
- 打开文件夹后，侧边栏（`Ctrl+Shift+L`）提供大纲、文章列表、文件树和全局搜索。
- `Ctrl+P` 快速打开：输入文件名的几个字母即可跳转。
- 未保存的修改会定时写入恢复区；异常退出后再次启动时会提示恢复。

## 视图

- 专注模式（`F8`）淡化当前段落以外的内容；打字机模式（`F9`）让当前行保持在窗口中间。
- `Ctrl+Shift+=` / `Ctrl+Shift+-` 缩放，`Ctrl+Shift+0` 还原（也可按住 `Ctrl` 滚动鼠标滚轮）。
- “主题”菜单切换主题；也可以把自己的主题放进主题文件夹（见“自定义主题”）。

## 导出

“文件 → 导出”可导出 HTML、PDF、图片；安装 [Pandoc](https://pandoc.org/installing.html) 后还可导出 Word、EPUB、LaTeX 等格式。“文件 → 页面设置”调整纸张、边距、页眉页脚。

## 设置与快捷键

`Ctrl+,` 打开偏好设置。所有菜单项都能在“快捷键”页重新绑定。完整命令列表见“帮助 → 快捷键”。
