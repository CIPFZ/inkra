# Inkra 1.0.0-beta.1

> **这是公开测试版（beta），不是正式版。** 功能已完整，但还没有经过大量真实文档与真实机器的检验。Inkra 只读写标准 `.md` 文件，所有保存都是原子写入，并有崩溃恢复；即便如此，**请在用 beta 版编辑重要文档前先备份**（复制文件夹，或使用 Git 等版本管理），发现问题请按文末方式反馈。

Inkra（墨刻）是用 100% Rust 编写的原生所见即所得 Markdown 编辑器。界面由 egui 在 GPU 上自绘，排版、语法高亮、数学公式、Mermaid 图表、PDF 导出全部为原生实现，不内嵌浏览器内核。磁盘上的文件始终是标准 `.md`。

[English below](#english)

## 主要功能

- **实时渲染**：光标所在块显示 Markdown 标记，其他块显示排版结果；`Ctrl+/` 切换源码模式。
- **完整的 GFM 与扩展**：表格编辑（Tab 导航、增删行列、对齐、拖拽列宽）、任务列表、脚注、`[TOC]`、GitHub 提示框、Front Matter、HTML 块子集。
- **数学与图表**：原生 TeX 子集排版（矩阵、`aligned`、自动编号与 `\eqref`），Mermaid 流程图、时序图、饼图；可选配置 `mmdc` 渲染其余类型。
- **工作区**：侧边栏大纲 / 文章列表 / 文件树，快速打开（`Ctrl+P`），全局搜索（`Ctrl+Shift+F`），自动保存、崩溃恢复、外部修改检测。
- **导出与导入**：HTML（两种）、PDF（书签、链接、页眉页脚）、图片；装有 Pandoc 时支持 docx、odt、epub、LaTeX 等格式的导入与导出。
- **外观**：Paper、Ink、Journal、Mono、Slate、Serif 六套原创主题与 Auto 明暗跟随，TOML 自定义主题，专注模式与打字机模式。
- **键盘优先**：所有动作都是命令，快捷键可在偏好设置中重新绑定；`inkra-cli` 提供 `convert`、`inspect`、`lint`、`fmt`、`run`。
- 简体中文与英文界面，AccessKit 无障碍支持，拼写检查（系统 Hunspell 词典）。

## 已知限制

- **安装包未签名**（代码签名与公证在 1.x 路线图中）：
  - **macOS**：dmg 与 `Inkra.app` 未签名、未公证，Gatekeeper 会阻止直接打开。首次请在 Finder 中右键 `Inkra.app` → 打开 → 再次确认"打开"。
  - **Windows**：SmartScreen 会提示"已保护你的电脑"，点"更多信息" → "仍要运行"。
- **arm64 未在真机上验证**：Windows arm64、Linux arm64 与 macOS 的 Apple 芯片部分只在 GitHub Actions 的 arm64 虚拟机 runner 上完成了安装与启动验证，尚未在 arm64 实体设备上测试。
- emoji 以单色字形显示（内置 Noto Emoji），彩色 emoji 尚不支持。
- Windows 11 一体化标题栏的最大化按钮不弹出"贴靠布局"浮层；需要时可在偏好设置中改用系统标题栏（`appearance.titleBar`）。
- Linux 在 Wayland 会话中默认经 XWayland 运行；原生 Wayland（`INKRA_WAYLAND=1`）尚未实测。
- 冷启动在虚拟 GPU 测试机上约 360 ms（DX12 会逐个探测全部显卡），单 GPU 实体机的数据还在收集——欢迎附上你的日志。

# Inkra 1.0.0-beta.1 (English)

> **This is a public beta, not a final release.** It is feature-complete but has not yet been tested on many real documents and machines. Inkra only reads and writes plain `.md` files, saves atomically and keeps crash recovery data; even so, **please back up important documents before editing them with the beta** (copy the folder, or use Git or another version control system), and report what you find as described at the end.

Inkra is a native WYSIWYM Markdown editor written in 100% Rust. The interface is drawn by egui on the GPU; layout, syntax highlighting, math, Mermaid diagrams and PDF export are all native, with no browser engine inside. Files on disk are always plain `.md`.

## Highlights

- **Live rendering**: the block under the caret shows its Markdown, every other block shows the result; `Ctrl+/` switches to source mode.
- **Full GFM plus extensions**: table editing (Tab navigation, rows and columns, alignment, column resizing), task lists, footnotes, `[TOC]`, GitHub alerts, front matter, an HTML block subset.
- **Math and diagrams**: a native TeX subset (matrices, `aligned`, automatic numbers and `\eqref`), Mermaid flowcharts, sequence diagrams and pie charts; an optional `mmdc` for the other types.
- **Workspace**: outline, article list and file tree in the sidebar, quick open (`Ctrl+P`), search in folder (`Ctrl+Shift+F`), auto-save, crash recovery, external change detection.
- **Export and import**: HTML (two styles), PDF (bookmarks, links, headers and footers), images; with Pandoc, docx, odt, epub, LaTeX and more both ways.
- **Appearance**: six original themes (Paper, Ink, Journal, Mono, Slate, Serif) and Auto light/dark, custom TOML themes, focus and typewriter modes.
- **Keyboard first**: every action is a command with a rebindable shortcut; `inkra-cli` offers `convert`, `inspect`, `lint`, `fmt` and `run`.
- Chinese and English interface, AccessKit accessibility, spell checking with the system's Hunspell dictionaries.

## Known limitations

- **The packages are not signed** (code signing and notarization are on the 1.x roadmap):
  - **macOS**: the dmg and `Inkra.app` are neither signed nor notarized, so Gatekeeper blocks a plain double-click. The first time, right-click `Inkra.app` in Finder → Open → confirm Open.
  - **Windows**: SmartScreen says "Windows protected your PC"; choose "More info" → "Run anyway".
- **arm64 is not verified on real hardware**: Windows arm64, Linux arm64 and the Apple silicon part of the macOS app were installed and started only on GitHub Actions' arm64 virtual machine runners, not yet on physical arm64 devices.
- Emoji are monochrome (bundled Noto Emoji); color emoji are not supported yet.
- On Windows 11 the integrated title bar's maximize button has no snap layout flyout; switch to the system title bar in Preferences (`appearance.titleBar`) if you need it.
- In Wayland sessions Linux builds run through XWayland by default; native Wayland (`INKRA_WAYLAND=1`) is untested.
- Cold start is about 360 ms on the virtual-GPU test machine (DX12 probes every adapter); numbers from single-GPU hardware are still being collected — your logs help.
