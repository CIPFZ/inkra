# Inkra 1.0.0-beta.1

Inkra（墨刻）的第一个公开测试版：用 100% Rust 编写的原生所见即所得 Markdown 编辑器。界面由 egui 在 GPU 上自绘，排版、语法高亮、数学公式、Mermaid 图表、PDF 导出全部为原生实现，不内嵌浏览器内核。磁盘上的文件始终是标准 `.md`。

[English below](#english)

## 主要功能

- **实时渲染**：光标所在块显示 Markdown 标记，其他块显示排版结果；`Ctrl+/` 切换源码模式。
- **完整的 GFM 与扩展**：表格编辑（Tab 导航、增删行列、对齐、拖拽列宽）、任务列表、脚注、`[TOC]`、GitHub 提示框、Front Matter、HTML 块子集。
- **数学与图表**：原生 TeX 子集排版（矩阵、`aligned`、自动编号与 `\eqref`），Mermaid 流程图、时序图、饼图；可选配置 `mmdc` 渲染其余类型。
- **工作区**：侧边栏大纲 / 文章列表 / 文件树，快速打开（`Ctrl+P`），全局搜索（`Ctrl+Shift+F`），自动保存、崩溃恢复、外部修改检测。
- **导出与导入**：HTML（两种）、PDF（书签、链接、页眉页脚）、图片；装有 Pandoc 时支持 docx、odt、epub、LaTeX 等格式的导入与导出。
- **外观**：Paper、Ink、Journal、Mono、Slate、Serif 六套原创主题与 Auto 明暗跟随，TOML 自定义主题，专注模式与打字机模式。
- **键盘优先**：所有动作都是命令，快捷键可在偏好设置中重新绑定；`inkra-cli` 提供 `convert`、`inspect`、`lint`、`fmt`、`run`。
- 简体中文与英文界面，AccessKit 无障碍支持，拼写检查（系统 Hunspell 词典）。

# Inkra 1.0.0-beta.1 (English)

The first public beta of Inkra, a native WYSIWYM Markdown editor written in 100% Rust. The interface is drawn by egui on the GPU; layout, syntax highlighting, math, Mermaid diagrams and PDF export are all native, with no browser engine inside. Files on disk are always plain `.md`.

## Highlights

- **Live rendering**: the block under the caret shows its Markdown, every other block shows the result; `Ctrl+/` switches to source mode.
- **Full GFM plus extensions**: table editing (Tab navigation, rows and columns, alignment, column resizing), task lists, footnotes, `[TOC]`, GitHub alerts, front matter, an HTML block subset.
- **Math and diagrams**: a native TeX subset (matrices, `aligned`, automatic numbers and `\eqref`), Mermaid flowcharts, sequence diagrams and pie charts; an optional `mmdc` for the other types.
- **Workspace**: outline, article list and file tree in the sidebar, quick open (`Ctrl+P`), search in folder (`Ctrl+Shift+F`), auto-save, crash recovery, external change detection.
- **Export and import**: HTML (two styles), PDF (bookmarks, links, headers and footers), images; with Pandoc, docx, odt, epub, LaTeX and more both ways.
- **Appearance**: six original themes (Paper, Ink, Journal, Mono, Slate, Serif) and Auto light/dark, custom TOML themes, focus and typewriter modes.
- **Keyboard first**: every action is a command with a rebindable shortcut; `inkra-cli` offers `convert`, `inspect`, `lint`, `fmt` and `run`.
- Chinese and English interface, AccessKit accessibility, spell checking with the system's Hunspell dictionaries.

## Known limitations

- Emoji are monochrome.
- On Windows 11 the integrated title bar's maximize button has no snap layout flyout (switch to the system title bar if you need it).
- Linux runs through XWayland by default; native Wayland (`INKRA_WAYLAND=1`) is untested.
- Cold start is about 360 ms on the virtual-GPU test machine; numbers from single-GPU hardware are still being collected.
