## 1. 产品概述

### 1.1 Inkra 是什么

Inkra 是一款面向写作者的 Markdown 编辑器。它去掉了传统 Markdown 工具的"源码 / 预览"双栏与模式切换，在单一视图内把 Markdown 实时渲染为排版后的文档，同时在光标所在位置保留可编辑的源码标记。用户像在文字处理器里一样写作，但磁盘上的文件始终是标准的纯文本 `.md`。

Inkra 完全用 Rust 编写：界面由 egui 在 GPU 上自绘，排版、语法高亮、数学公式、图表、PDF 生成全部为原生实现，不内嵌浏览器内核，不依赖 JavaScript 运行时。由此获得毫秒级启动、极低的内存占用和三平台一致的体验。

### 1.2 目标用户

1. 技术写作者与开发者：写文档、README、博客，依赖代码块高亮、表格、图表。
2. 学生与研究者：数学公式、脚注、引用、导出 PDF。
3. 笔记与知识管理用户：文件夹即笔记库，依赖侧边栏、快速打开、全局搜索。
4. 长文作者：专注模式、打字机模式、字数统计、EPUB/DOCX 导出。

### 1.3 产品原则（实现任何功能时的决策依据）

1. **内容优先，界面退让**：默认界面只有文档本身；侧边栏、工具栏、状态栏都可隐藏，且默认极简。
2. **文件就是纯文本**：永远不引入私有格式。任何渲染效果都必须可以无损序列化回标准 Markdown（GFM + 第 4 章定义的扩展），用其他编辑器打开结果一致。
3. **编辑即渲染，无模式切换**：用户不需要知道"预览"这个概念。源码模式只是逃生舱。
4. **键盘优先**：所有操作有快捷键；Markdown 语法输入即是最快的格式化方式。
5. **可预测**：相同输入在相同状态下产生相同结果；自动化行为（自动配对、智能标点、列表延续）必须可以在偏好设置中关闭。
6. **永不丢失内容**：自动保存、崩溃恢复、外部修改检测；任何解析失败都降级为显示原文而非吞掉文本。
7. **原生性能**：空文档启动 < 300 ms，10 万字文档输入延迟 < 16 ms，内存占用控制在第 2.5 节预算内。

### 1.4 目标（Goals）

- G1：完整的 GFM 语法支持与第 4 章定义的扩展语法（数学、图表、脚注、目录、提示框等），以及第 3 章定义的实时渲染交互。
- G2：完整的工作区能力：侧边栏三视图、快速打开、全局搜索、文件管理（第 5 章）。
- G3：写作模式与外观系统：专注、打字机、主题、自定义样式（第 6、7 章）。
- G4：导入导出能力：PDF、HTML、图片，及通过 Pandoc 的扩展格式（第 8 章）。
- G5：完整的偏好设置与可自定义快捷键体系（第 9、10 章）。
- G6：所有功能通过统一命令系统暴露，并提供 CLI 与控制通道，便于自动化与 AI 驱动（第 11 章）。
- G7：Windows、macOS、Linux 三平台原生体验一致。

### 1.5 非目标（Non-Goals，1.0 明确不做）

- 不做云同步、账号系统、协作编辑、评论。
- 不做插件系统（1.0 不开放脚本扩展；通过命令系统与 CLI 满足自动化）。
- 不做 Web 版本：不提供 WebAssembly 构建目标，不内嵌 WebView，不引入 JavaScript 运行时。所有渲染包括公式与图表都用 Rust 原生实现，或由用户显式配置的外部进程完成。
- 不做富文本（非 Markdown）编辑能力，如任意字体颜色、字号；凡 Markdown 无法表达的格式一律不提供。
- 不做多光标编辑。

### 1.6 技术边界声明

| 领域 | Inkra 的实现方式 |
|---|---|
| 界面与渲染 | egui 自绘 + 自研文档排版引擎，wgpu GPU 合成 |
| 主题 | 声明式 TOML 主题文件（第 7 章） |
| 数学公式 | Rust 原生 TeX 子集排版引擎（第 2.4 节） |
| 图表 | Rust 原生 Mermaid 子集解析与布局；可选外部 `mmdc` 兜底 |
| 代码高亮 | syntect（Sublime 语法定义）；tree-sitter 为 P2 可选 |
| PDF 导出 | 自研分页 + krilla 生成 |
| HTML 导入导出 | 纯 Rust 解析与生成（html5ever），HTML 仅作为文件格式，不作为运行时 |
| 构建目标 | 仅原生桌面二进制 |

### 2.3 核心架构决策

**AD-1 自研增量 Markdown 解析器而非直接用 pulldown-cmark**
理由：实时渲染编辑需要（a）每个 AST 节点精确到字节的源码范围，包括标记符号本身的位置（`**` 在哪里）；（b）局部重解析：输入一个字符只重解析所在块及受影响的相邻块；（c）容错：未闭合的 `**`、半成品表格必须按"输入中"状态渲染而不是报错；（d）序列化：AST 必须能无损写回源码。pulldown-cmark 是只读的事件流解析器，不满足 (a)(b)(d)。实现时参考 CommonMark 规范的两阶段算法（先块后行内），并用 CommonMark spec 的 652 个例子与 GFM 扩展例子作为一致性测试（允许列出有意偏离的例子）。

**AD-2 文档的唯一真相是源码（rope），AST 是派生缓存**
所有编辑操作都表达为对源码的 `Transaction { edits: Vec<(Range<usize>, String)> }`。UI 上的"富文本操作"（如点击任务复选框、拖拽表格列）最终都转换为源码编辑。这保证撤销/重做、源码模式与实时渲染模式的切换天然一致。

**AD-3 命令系统**
每个用户可触发动作都是一个命令，拥有稳定 id（`format.bold`、`paragraph.heading1`、`view.toggleSidebar`）、参数 schema、可用性判断、撤销组。菜单、快捷键、工具栏、右键菜单、CLI、控制通道都只是命令的入口。`cargo xtask commands` 从代码生成 `docs/commands.md`。

**AD-4 布局缓存与按需渲染**
每个块维护一份布局缓存（包含它的高度和子元素位置），以块源码的哈希 + 可用宽度 + 主题版本为键。滚动时只排版可见区域及其上下各一屏；文档总高度用已缓存高度 + 未布局块的估算高度，滚动条随布局完成逐步收敛。目标：10 万字文档输入一字符的"解析 + 布局 + 绘制"总时间 < 8 ms。

**AD-5 后台线程边界**
UI 线程只做：输入处理、增量解析、可见区域布局、绘制。以下任务在后台线程并通过 channel 回传：图片解码、代码高亮（首次加载语法定义）、数学公式排版（结果缓存）、图表布局、全局搜索、导出、Pandoc、拼写检查、文件监控。后台结果到达时调用 `ctx.request_repaint()`。

**AD-6 无 unsafe，平台特性走经审计的 crate**
workspace 级 `#![forbid(unsafe_code)]`，macOS 的 Apple Event（Finder 双击打开）、Windows 注册表文件关联等通过独立 crate 或构建脚本处理。
[回填 2026-10-12] 唯一例外：`apps/inkra/src/platform_windows.rs` 的 Win32 FFI（`AttachConsole` 使 GUI 子系统程序的 `--version` 在终端可见；`SetCurrentProcessExplicitAppUserModelID` 设置 UI-050 要求的 AppUserModelID；[回填 2026-10-13] `SystemParametersInfoW(SPI_GETCLIENTAREAANIMATION)` 读取 UI-033 的"减少动画"设置）。该 crate 将 `unsafe_code` 由 `forbid` 降为 `deny`，仅在该模块 `allow`，`cargo xtask layering` 维护例外白名单。

### 2.4 数学与图表渲染策略（无 JS 运行时的关键难点）

**数学（P1）**
- 解析 TeX 数学子集：AMSmath 常用命令（`\frac`、`\sqrt`、`\sum`、`\int`、`\lim`、上下标、`\left...\right`、矩阵环境 `matrix/pmatrix/bmatrix/vmatrix/cases/aligned/align*/gather`、`\text`、`\mathbb/\mathcal/\mathrm/\mathbf`、希腊字母、运算符、箭头、`\overline/\underline/\hat/\vec/\dot`、`\color`、`\boxed`、`\tag`）。
- 扩展：mhchem `\ce{}` 的常用子集（P2）、`\label/\ref/\eqref` 与自动编号（P1，受偏好设置控制）、`\newcommand` 文档内宏（P2）。
- 布局算法参照 TeX 的 Appendix G 简化版，使用 OpenType MATH 表字体（Latin Modern Math 或 STIX Two Math）读取参数。
- 不支持的命令：以红色波浪线标记该段公式并显示原始 TeX 文本，绝不崩溃或吞文本。
- 公式渲染结果按（TeX 源 + 字号 + 颜色）缓存为矢量路径，可直接用于 PDF 导出。

**图表（P1 子集，P2 完整）**
- P1：`mermaid` 的 `flowchart/graph`（TD/LR/BT/RL，节点形状 `[] () {} (()) [[]] [()] >]`，边 `--> --- -.-> ==> -->|label|`，subgraph）、`sequenceDiagram`（participant、箭头 6 种、loop/alt/opt/par、note、activate）、`pie`。
- P2：`gantt`、`classDiagram`、`stateDiagram-v2`、`erDiagram`、`journey`、`gitGraph`、`mindmap`、`timeline`、`xychart`、`quadrantChart`、`sankey`、`block`、`packet`、`kanban`、`architecture`、`radar`、`treemap`。
- 兜底：偏好设置可指定外部 `mmdc` 可执行文件；若设置且本地渲染器不支持该图表类型，则调用 `mmdc -i - -o svg` 得到 SVG 用 resvg 渲染。
- 图表布局在后台线程完成，结果缓存；编辑中实时更新（防抖 150 ms），解析错误显示在图表位置下方。

## 3. 编辑器核心：实时渲染视图与文本编辑

本章是整个产品的灵魂。实现者必须先完整实现本章再做其他任何功能。

### 3.1 实时渲染视图基本模型

**ED-001 (P0) 单视图实时渲染**
文档以渲染后的排版形式显示（标题变大、`**粗体**` 显示为粗体且不显示星号、图片显示为图片）。不存在独立的预览面板，不存在"编辑/预览"切换按钮（源码模式除外，见 3.9）。

**ED-002 (P0) 活动块显示源标记**
光标进入某个块级元素时，该块"展开"显示其 Markdown 源标记：
- 标题：显示前导 `# ` 符号，`#` 以较淡的标记色显示，标题文字仍以标题字号渲染。
- 段落中的行内元素：光标所在**行内元素**展开显示标记（如光标进入粗体文字时显示 `**`），其他行内元素保持渲染状态。光标离开后标记隐藏。
- 代码块：始终显示为代码块外观，光标进入时显示语言选择器与右上角工具按钮（复制、换行切换）。
- 数学块：光标进入时块内部切换为 TeX 源码编辑区，并在其下方显示实时渲染预览。
- 表格：始终以表格网格显示，不显示 `|` 源码；光标进入单元格直接编辑文本。
- 链接：光标进入时显示 `[text](url)` 完整源码；光标离开隐藏为可点击链接文本。
- 图片：光标在图片所在行时，在图片下方显示 `![alt](src)` 源码编辑框，其余时间只显示图片。
- 脚注引用、行内公式、HTML 行内：同链接逻辑。
- 引用块、列表：始终渲染为引用/列表外观，不显示 `>` 或 `-` 源符号，通过缩进与竖线/项目符号表达。
- 水平线、TOC、Front Matter：Front Matter 始终显示为灰色代码风格块；水平线为线条，光标无法进入其内部（光标落在其前后）。

**ED-003 (P0) 标记可见性的过渡**
标记的显示与隐藏为即时切换（不做动画），光标离开后文本不得发生水平抖动超过 1 帧。实现建议：活动块与非活动块使用不同布局缓存键。

**ED-004 (P0) 语法输入触发渲染**
用户输入 Markdown 语法后即时转换：
- `# ` + 文本 + Enter → 标题（实际上 `# ` 一经输入该行就按标题渲染，Enter 后新段落为普通段落）。
- `- `、`* `、`+ ` + 空格 → 无序列表项；`1. ` → 有序列表项；`- [ ] ` → 任务项。
- `> ` → 引用块。
- ``` ``` ``` + 可选语言 + Enter → 代码块。
- `$$` + Enter → 数学块。
- `---`、`***`、`___` + Enter → 水平线。
- `|a|b|` + Enter → 表格（至少包含一个 `|`；自动补出分隔行并创建含表头与一行数据的两行表格）。
- `[TOC]` + Enter → 目录块。
- `**text**`、`*text*`、`` `code` ``、`~~text~~`、`==text==`（需开启高亮）、`^text^`、`~text~`（需开启上下标）、`$x$`（需开启行内公式）→ 输入闭合符后立即渲染为对应行内样式。
- `:smile` → 弹出 emoji 自动补全（见 3.7）。

**ED-005 (P0) 块级元素之间的光标移动**
- 上下方向键在渲染后的行之间移动，而不是源码行；跨块时进入相邻块的最近视觉位置。
- 从段落末尾按 Right 进入下一个块的开头；从代码块最后一行 Down 离开代码块到下一块。
- 光标在表格内上下移动在单元格间移动，到达首行/末行再按 Up/Down 离开表格。
- 光标不可进入：水平线、TOC 块内部、图片本体（光标落在图片前或后）。
- 光标进入数学块、图表块、HTML 块时进入其源码编辑区域。

**ED-006 (P0) 在特殊块前后插入段落**
当文档开头是表格/代码块/数学块等不可直接"向上创建段落"的块时，光标在块开头按 `Ctrl+Enter` 或在块上方点击空白区域可插入空段落；文档末尾始终保留一个可点击的空白区域，点击后在末尾新建段落。

### 3.2 文本输入与基本编辑

**ED-010 (P0) 基本输入**
支持 Unicode 全部字符输入、IME 组合输入（中日韩）；组合中文字（预编辑文本）以下划线显示在光标位置，候选框位置跟随光标（egui 的 `ime_rect` 必须每帧更新为光标屏幕矩形）。

**ED-011 (P0) 选区**
- 鼠标拖拽、Shift+方向键、Shift+点击扩展选区。
- 双击选词（按 Unicode 词边界，CJK 按字或分词），三击选段落。
- `Ctrl+A` 全选当前文档；在代码块、表格单元格内 `Ctrl+A` 先选当前块/单元格内容，再按一次选全文。
- 选区可以跨越多个块；跨块选区在渲染视图中高亮渲染后的区域。
- 选区颜色跟随主题。

**ED-012 (P0) 删除行为**
- Backspace 在块开头：标题变为段落（移除 `#`）；列表项变为段落（移除项目符号，若有子列表则提升）；引用块内第一段变为普通段落（移除一级 `>`）；空代码块删除整个块；普通段落开头与上一块合并（上一块为表格/代码块时光标移入其末尾而不合并）。
- Delete 在块结尾：与下一块合并（规则对称）。
- `Ctrl+Backspace` / `Alt+Backspace`（mac）删除前一个词；`Ctrl+Shift+Backspace`（mac：`Cmd+Backspace`）删除到行首。
- 选中表格整行/整列时 Delete 删除内容而非结构；删除结构用表格菜单。

**ED-013 (P0) Enter 行为**
- 段落中 Enter：分段（源码中插入空行）。
- `Shift+Enter`：软换行（源码插入 `\n`，不加两个空格）。偏好设置可选硬换行形式（行尾两个空格或 `<br>`），默认源码只写一个换行符。
- 标题末尾 Enter：新建普通段落。
- 列表项末尾 Enter：新建同级列表项，自动编号递增；空列表项再按 Enter：结束列表变为段落（嵌套时先提升一级）。
- 任务项末尾 Enter：新建未勾选任务项。
- 引用块内 Enter：引用内新段落；空段落再 Enter：退出引用。
- 代码块内 Enter：插入换行并保持上一行缩进；代码块结尾空行连按 Enter 不退出，用 Down 方向键、鼠标点击或 `Ctrl+Enter` 退出。
- 表格单元格内 Enter：不换行，`Shift+Enter` 插入 `<br>`；`Ctrl+Enter` 在当前行下方新建一行；在最后一行按 Enter 亦新建一行。
- 数学块源码内 Enter：换行；`Ctrl+Enter` 或 Esc 完成编辑退出块。
- 光标在块中间 Enter：拆分为两个同类型块（标题拆分后下半为段落）。

**ED-014 (P0) Tab 行为**
- 列表项中 Tab：增加缩进级别（嵌套），`Shift+Tab` 减少；同时作用于选中的多个项。
- 表格单元格中 Tab：移至下一单元格，最后一格 Tab 新建行；`Shift+Tab` 上一格。
- 代码块中 Tab：插入制表符或 N 个空格（偏好设置，默认 4 空格）；选中多行 Tab 整体缩进。
- 普通段落 Tab：偏好设置"段落首行缩进"决定插入 2 个全角空格还是忽略；默认插入 4 个空格并作为普通文本原样保留。

**ED-015 (P0) 撤销与重做**
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做。
- 撤销粒度：连续输入的字符按词/停顿 500 ms 合并为一组；每个命令执行为独立一组；粘贴为一组；自动化行为（如列表自动编号修正）合并进触发它的用户操作组。
- 撤销后光标与选区恢复到操作前位置，并滚动到可见。
- 撤销栈大小默认无限（内存受限时裁剪至最近 1000 组），切换文件保留各自撤销栈直到关闭。
- 源码模式与实时渲染模式共享同一撤销栈。

**ED-016 (P0) 剪切 / 复制 / 粘贴**
- 复制选区：同时写入剪贴板 `text/plain`（Markdown 源码）与 `text/html`（渲染后的 HTML，带内联基础样式，便于粘贴到 Word、微信公众号等富文本环境）。
- 偏好设置"复制时默认复制 Markdown 源码 / 纯文本"。
- 右键菜单提供：`复制为 Markdown`、`复制为 HTML`、`复制为纯文本（无标记）`、`复制为 HTML 代码`。
- 在代码块内复制只复制代码文本。
- 粘贴规则（按优先级）：
  1. 剪贴板含图片位图 → 按图片插入流程（3.6）。
  2. 剪贴板含文件路径列表 → 图片文件按图片插入；`.md` 文件插入链接；其他文件插入链接。
  3. 剪贴板含 `text/html` 且来源非本应用 → 转换 HTML 为 Markdown 插入（标题、段落、列表、表格、链接、图片、粗斜体、代码、引用均需转换；不支持的标签取其文本）。`Ctrl+Shift+V` 强制粘贴为纯文本。
  4. 纯文本：若在代码块中 → 原样插入；否则 → 作为 Markdown 源码插入并重新解析（粘贴 `# Title` 会成为标题）。
  5. 粘贴 URL 到有选区的文本上 → 把选区变为链接 `[selection](url)`。
  6. 粘贴从 ChatGPT 等 AI 工具复制的数学表达式（`\(...\)`、`\[...\]` 或 HTML 中的 KaTeX/MathML）→ 转为 `$...$` / `$$...$$`。
- 粘贴大段文本（> 1 MB）显示进度并在后台解析。
  [回填 2026-10-13] 增量解析器对 1 MB 文本的全量解析约 50 ms（M1 基准），粘贴 1 MB 在一帧多的时间内完成，故不单独显示进度条；超过 4 MB 的粘贴同样作为单个 Transaction 写入，解析在下一帧完成。

**ED-017 (P1) 拖拽**
- 拖拽选中文本到文档其他位置：移动；按住 Ctrl（mac：Option）复制。
- 从系统拖入文件：图片→插入图片；`.md`→打开文件（偏好可改为插入链接）；其他→插入链接。
- 从侧边栏文件树拖入文档：插入相对路径链接或图片。
- 拖拽图片/视频文件进入时显示插入位置指示线。

**ED-018 (P1) 行/段落移动**
`Alt+Up` / `Alt+Down` 将当前段落、列表项、表格行与上/下相邻元素交换位置。在表格内移动行，在列表内移动项（含其子列表），其他情况移动块。

**ED-019 (P1) 多光标**
不实现。记录为非目标，见 1.5。

**ED-020 (P0) 光标与滚动**
- 光标闪烁 530 ms 周期，输入时停止闪烁并保持显示；窗口失焦时隐藏光标。[回填 2026-10-13] 无输入 30 s 后停止闪烁并保持显示，以满足 2.5 节"空闲 CPU 0%"预算。
- 光标移出可见区域时自动滚动使其可见，并留 2 行边距。
- 鼠标滚轮、触控板惯性滚动、拖动滚动条；`PageUp/PageDown`、`Ctrl+Home/End`。
- 偏好设置"打字机模式"见第 6 章。

### 3.5 表格编辑

表格是写作者最依赖的富交互之一，细节必须到位。

**ED-080 (P0) 表格呈现**
以网格显示，表头加粗，列宽按内容自适应（最小 60 px，最大为编辑区宽度）。表格宽于编辑区时水平滚动。对齐方式（`:---`、`:---:`、`---:`）影响单元格文本对齐。表格内支持行内元素（粗斜体、代码、链接、图片、行内公式），但不支持块级元素。

**ED-081 (P0) 单元格编辑**

**ED-082 (P0) 表格工具条**

**ED-083 (P0) 表格命令**

**ED-084 (P1) 鼠标调整**

**ED-085 (P0) 源码格式化**
表格序列化时对齐各列的 `|`（用空格填充，CJK 字符按 2 宽度），分隔行按列宽填充 `-`，保留对齐冒号。偏好设置可关闭对齐填充。

### 3.6 图片处理

**ED-090 (P0) 图片显示**
`![alt](src "title")` 与 `<img src width height>` 均渲染为图片。支持：本地绝对/相对路径、`file://`、`http(s)://`（后台下载并缓存，默认开启，可关闭）、`data:` base64。图片最大宽度为编辑区宽度，等比缩放；`<img width="400">` 或 `<img style="zoom:50%;">` 按指定大小。加载中显示占位框，失败显示破损图标 + 路径 + 重试/修复路径按钮。

**ED-091 (P0) 相对路径解析**
解析优先级：Front Matter 中的 `inkra-root-url` → 偏好设置的全局图片根目录 → 当前文件所在目录。以 `/` 开头的路径在设置了 root-url 时相对于 root-url。

**ED-092 (P0) 插入图片的来源与"插入时动作"**
来源：粘贴位图、拖拽文件、`Ctrl+Shift+I` 选择文件、粘贴/拖拽网络图片 URL。
偏好设置"插入图片时"：
1. 不做任何操作（直接使用原路径或 URL）。
2. 复制图片到 `./${filename}.assets` 文件夹（`${filename}` 为当前文档名）。
3. 复制图片到自定义文件夹（支持 `${filename}`、`${filepath}` 变量，相对或绝对路径）。
4. 上传图片（见 ED-094）。
附加开关：对本地文件也应用上述规则；对网络图片也应用上述规则；插入时优先使用相对路径；自动转义图片 URL 中的空格等字符。
粘贴位图时文件名为 `image-YYYYMMDDHHmmssSSS.png`。

**ED-093 (P1) 图片操作**
点击图片选中（显示边框）；右键菜单：复制图片、复制图片地址、在文件夹中显示、在新窗口打开、放大查看（zoom 50/67/100%）、重新加载、上传图片、转为本地图片（下载网络图片到 assets）、编辑 alt/title/尺寸、删除。选中图片时拖动右下角手柄调整宽度（写入 `<img>` 或 `{zoom}`，偏好选择）。双击图片用系统默认查看器打开。

**ED-094 (P2) 图片上传**
上传服务选项：PicGo 应用（命令行 `picgo upload`）、PicList、uPic（mac）、iPic（mac）、自定义命令（用户填写可执行文件与参数，输出一行一个 URL）。提供"验证图片上传选项"按钮执行一次测试上传。右键单个图片"上传图片"与菜单"格式→图片→上传所有本地图片"。

**ED-095 (P2) 视频与音频**
`<video src controls>`、`<audio>` 显示为占位卡片（显示文件名、时长，点击用系统播放器打开）；拖入视频文件生成 `<video src="..." controls></video>`。1.0 不内嵌播放器。

### 3.7 自动化辅助

**ED-100 (P0) 自动配对**
输入 `(`、`[`、`{`、`"`、`'`、`` ` ``、`$`（行内公式开启时）自动插入闭合符并把光标置中；在闭合符前输入相同闭合符时跳过；在选区上输入开符号时包裹选区。偏好设置"自动配对括号与引号"开关。单独开关"自动配对 Markdown 符号"（`*`、`_`、`~`、`=`）。删除开符号时若紧邻闭合符一并删除。代码块中仅配对括号与引号，不配对 Markdown 符号。

**ED-101 (P0) 列表延续与自动编号**
输入列表项后 Enter 自动续写标记（见 ED-013）。有序列表自动重编号：在中间插入/删除项后，源码中的编号重新连续；偏好设置"有序列表总是从 1 开始"或"保留起始编号"。

**ED-102 (P1) 智能标点**
偏好设置开启后，输入 `"` 与 `'` 根据上下文转为弯引号 `“ ” ‘ ’`；`--` 转 en dash、`---` 转 em dash（可选）；`...` 转省略号（可选）。在代码、行内代码、公式、链接地址内不生效。按 Backspace 可撤回转换（恢复直引号）。

**ED-103 (P1) Emoji 自动补全**
输入 `:` 后接 ≥ 2 个字母弹出补全列表（最多 10 项，显示 emoji 与短码），Enter/Tab 选中插入 Unicode emoji（偏好可选插入 `:shortcode:` 文本）。Esc 关闭。偏好"输入 : 时显示 emoji 自动补全"开关。数据源：GitHub gemoji 短码表（MIT）。

**ED-104 (P1) 拼写检查**
红色波浪线标注拼写错误的词（英文默认开启，可选词典：en-US、en-GB、de、fr、es、pt、ru、it、pl 等 Hunspell 词典）。右键显示建议、"添加到词典"、"忽略"。不检查：代码、公式、链接 URL、HTML、Front Matter。偏好：拼写检查开关、自动纠正（P2，不做）、词典语言。

**ED-105 (P1) 自动补全**
- 输入 `[` 后弹出当前文档的标题列表以插入内部链接 `[text](#heading)`。
- 输入 `[^` 弹出现有脚注 id。
- 代码块语言选择器输入时模糊匹配语言列表。
- 偏好："自动补全 Markdown 链接"开关。

**ED-106 (P1) 换行符与编码**
读取时自动检测 UTF-8（含 BOM）、UTF-16 LE/BE、GBK/GB18030（偏好可指定默认）；保存时保持原编码与原换行符（LF/CRLF），新文件使用偏好设置的默认值（LF，UTF-8 无 BOM）。文件尾是否保留换行跟随原文件。

**ED-107 (P2) 空格可见性**
"显示格式标记"（视图菜单）在渲染视图中用淡色点显示连续空格和尾随空格，`↵` 显示软换行。默认关闭。

### 3.8 查找与替换

**ED-110 (P0) 文档内查找**
`Ctrl+F` 在编辑区顶部弹出查找条：输入框、匹配数 `3/17`、上一个/下一个（`Shift+Enter`/`Enter`，`Shift+F3`/`F3`）、区分大小写、全字匹配、正则表达式开关、关闭（Esc）。实时高亮全部匹配（渲染视图中按渲染后文本匹配，即搜索 "bold" 可匹配 `**bold**` 的内容）；当前匹配不同颜色并滚动居中。选区非空时打开查找条自动填入选区文本。

**ED-111 (P0) 替换**
`Ctrl+H` 展开替换行：替换输入框、替换当前、全部替换。正则模式支持 `$1` 组引用。替换为一个撤销组。在代码块与公式源码中同样替换（按源码匹配），其他位置按渲染后文本匹配并映射回源码范围。

**ED-112 (P1) 替换的源码安全**
替换不会破坏 Markdown 结构：若替换目标跨越标记（如匹配 `old**te` 跨越粗体边界），按源码进行并在替换后重新解析；用户可见结果与源码保持一致即可。

### 3.9 源码模式

**ED-120 (P0) 切换**
`Ctrl+/` 在实时渲染与源码模式间切换；左下角状态栏 `</>` 按钮等价；切换时保持光标在同一源码偏移，并保持滚动位置。

**ED-121 (P0) 源码编辑器能力**
等宽字体；行号（偏好可关闭）；Markdown 语法高亮（标题、强调、代码、链接、列表标记、引用、表格分隔、HTML 用不同颜色，配色由主题的 `code.syntax_theme` 决定）；自动配对；列表延续；Tab 缩进；查找替换；撤销栈共享；拼写检查；长行软换行（偏好可改为不换行并水平滚动）。

**ED-122 (P1) 源码模式下的限制**
源码模式不显示图片、表格渲染、公式渲染；大纲侧栏仍然可用（实时从源码解析标题）。所有 `format.*` 与 `paragraph.*` 命令在源码模式下仍然可用，并直接编辑源码。

### 3.10 右键菜单

**ED-130 (P0)** 编辑区右键菜单内容随光标位置变化：
- 通用：剪切、复制、粘贴、粘贴为纯文本、复制为（子菜单：Markdown / HTML / 纯文本 / HTML 代码）、全选、插入（子菜单：图片、链接、表格、代码块、公式块、脚注、水平线、TOC）、段落类型（子菜单同 3.4）、列表类型、拼写建议（有错词时置顶）。
- 链接上：打开链接、复制链接地址、编辑链接、移除链接。
- 图片上：3.6 的图片菜单。
- 表格内：表格菜单。
- 代码块内：复制代码、切换语言、切换自动换行、切换行号。
- 公式上：复制 TeX、复制为图片（P2）、编辑。
- 任务项：切换完成状态。

## 4. Markdown 语法支持（解析与渲染规范）

Inkra 遵循 GFM，并实现本章定义的扩展语法。本章每条需求都应有对应的解析单元测试、序列化回写测试、渲染快照测试。

### 4.1 块级元素

**MD-001 (P0) 段落与换行**
- 连续非空行构成一个段落；在 Inkra 中按一次 Enter 即分段（源码写入空行）。
- 软换行在编辑器中显示为换行；导出 HTML 时按 CommonMark 规则视为空格，偏好"导出时保留换行符"可改为导出 `<br>`。
- 硬换行：行尾两个空格或 `\` 或 `<br>` 渲染为换行，导出亦为 `<br>`。
- 偏好："段落首行缩进"（仅显示用，不写入源码，不影响列表与引用）。

**MD-002 (P0) 标题**
ATX 标题 `#` 至 `######`，`#` 后默认允许无空格（宽松模式）；开启偏好"严格模式"后要求空格（MD-016）。闭合 `#` 可选且去除。Setext 标题（`===`、`---` 下划线）解析支持，渲染为标题；用命令修改时转换为 ATX 形式。标题生成锚点 id（GitHub 算法：小写、空格转 `-`、去标点，重复加 `-1`），用于内部链接与 TOC。偏好"标题自动编号"仅为渲染选项，不写入源码。

**MD-003 (P0) 引用块**
`>` 开头，支持惰性延续、嵌套、内含任意块级元素（列表、代码块、标题）。渲染为左侧竖线 + 缩进；嵌套为多条竖线。

**MD-004 (P0) GitHub Alerts**
`> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 作为引用块第一行时渲染为带图标和颜色的提示框。类型标签区分大小写不敏感。导出 HTML 为 `<div class="markdown-alert markdown-alert-note">`。

**MD-005 (P0) 列表**
- 无序 `-`、`*`、`+`；有序 `1.`、`1)`；起始编号保留（`3.` 开头从 3 开始）。
- 嵌套靠缩进（2 或 4 空格或制表符，按 CommonMark 列表项缩进规则）；渲染为层级项目符号（• ◦ ▪ 循环）或编号（所有层级均使用阿拉伯数字，不自动切换为字母或罗马数字）。
- 松散与紧凑列表：源码中项之间有空行为松散（项之间有段距），否则紧凑；编辑器按源码呈现松紧差异，Enter 新建项时沿用当前列表的松紧。
- 列表项内可含多个段落、代码块、引用、表格（需缩进对齐）。
- 列表标记样式切换（ED-062）。

**MD-006 (P0) 任务列表**
`- [ ]`、`- [x]`、`- [X]` 渲染为复选框，点击切换并写回源码 `[x]`/`[ ]`；完成项文字可按主题设置为删除线/灰色。嵌套任务列表支持。

**MD-007 (P0) 围栏代码块**
- ```` ``` ```` 或 `~~~` 围栏，≥ 3 个，闭合围栏长度 ≥ 开启；信息字符串第一个词为语言。
- 不支持缩进式代码块（4 空格）：缩进文本显示为普通段落，严格模式下亦不解析为代码块。
- 渲染：等宽字体、背景色、语法高亮（syntect，语言别名表至少覆盖：`js/javascript`、`ts`、`py`、`rb`、`sh/bash/shell/zsh`、`c/cpp/c++`、`cs`、`java`、`kt`、`go`、`rs/rust`、`swift`、`php`、`html/xml`、`css/scss/less`、`json/yaml/toml`、`sql`、`md/markdown`、`diff`、`dockerfile`、`makefile`、`latex/tex`、`r`、`matlab`、`lua`、`perl`、`dart`、`scala`、`haskell`、`elixir`、`erlang`、`clojure`、`lisp`、`ocaml`、`fsharp`、`powershell`、`bat`、`ini`、`nginx`、`graphql`、`proto`、`gas/asm`、`url` 等）。未知语言显示纯文本。
- 右上角悬浮工具：语言选择器（可编辑、模糊匹配）、复制按钮；偏好：显示行号、自动换行（默认关闭，开启时长行折行；关闭时水平滚动）。
- 代码块内 Tab 缩进、自动配对括号；不解析 Markdown。
- 特殊语言 `mermaid`、`flow`、`sequence` 渲染为图表块（4.5）；不提供 `math` 围栏，数学块只用 `$$`。

**MD-008 (P1) 数学块**
`$$` 单独一行开始和结束（或同一行 `$$...$$`），内部 TeX 渲染为居中公式。`\[...\]` 作为块公式分隔符亦支持（偏好可关闭）。光标进入时展开源码编辑并实时预览。自动编号（偏好）：AMS 规则（仅 `\begin{equation}` 等编号环境）或全部块公式编号，`\tag{}` 覆盖，`\label`/`\ref` 交叉引用可点击跳转。

**MD-009 (P0) 表格**
GFM 表格：表头行、分隔行（至少 3 个 `-`，可带 `:` 对齐）、数据行；首列 `|` 可省略；单元格数不一致时补空或截断（GFM 规则）；`\|` 转义。见 3.5 的编辑交互。

**MD-010 (P1) 脚注**
`[^id]` 引用，`[^id]: 内容` 定义（定义可多段，后续段缩进 4 空格）。引用渲染为上标数字（按出现顺序编号而非 id），悬停显示定义内容气泡，点击跳到定义；编辑器内脚注定义按源码所在位置渲染，导出 HTML/PDF 时聚合到文档末尾。

**MD-011 (P0) 水平线**
`---`、`***`、`___`（≥ 3，可含空格）渲染为水平线。注意与 Setext 标题、列表项 `- - -` 的歧义，按 CommonMark 规则。

**MD-012 (P1) YAML Front Matter**
文档首行为 `---` 且后续存在闭合 `---` 行则解析为 Front Matter。渲染为灰色等宽块，可直接编辑；不校验 YAML 合法性（仅尝试解析用于提取 `inkra-root-url`、`inkra-copy-images-to`、`title` 等字段）。导出时按格式处理：HTML 不输出；Pandoc 保留；PDF 不输出。

**MD-013 (P1) 目录 `[TOC]`**
单独一段 `[TOC]` 渲染为当前文档标题目录（可点击跳转），随标题编辑实时更新。偏好可限制层级（默认 1 至 6）。导出时生成静态目录与锚点链接。

**MD-014 (P1) HTML 块**
以 HTML 块级标签开头的段落（CommonMark 7 种类型）视为 HTML 块。渲染策略：
- 支持渲染的子集：`<div>`、`<p>`、`<span>`、`<img>`、`<a>`、`<br>`、`<b>/<strong>`、`<i>/<em>`、`<u>`、`<s>/<del>`、`<sup>`、`<sub>`、`<mark>`、`<kbd>`、`<code>`、`<pre>`、`<center>`、`<font color>`、`<details>/<summary>`（可折叠）、`<table>`（简单表格）、`<video>/<audio>`（占位卡片）、`<iframe>`（占位卡片，显示 src）。
- 支持的 style 属性子集：`color`、`background-color`、`text-align`、`font-size`、`font-weight`、`font-style`、`zoom`（图片）、`width/height`（图片）、`margin/padding`（忽略）。

光标所在行始终保持在视口垂直中央：光标移动或输入时滚动文档以对齐（平滑滚动 80 ms，可在偏好中关闭动画）；文档首尾允许出现空白区域以便首行/末行也能居中。鼠标滚轮滚动临时脱离，下次光标移动再次对齐。

**WM-003 (P0) 全屏** `F11` / mac `Ctrl+Cmd+F`
隐藏系统标题栏与菜单栏（Windows/Linux 菜单栏在 Alt 下临时出现或通过汉堡按钮，见 10.1）。

**WM-004 (P1) 页面宽度与边距**
偏好：编辑区最大宽度（默认主题决定，如 860 px）、自动隐藏滚动条、"宽屏时居中"。主题变量可覆盖。

**WM-005 (P1) 安静启动**
无动画、无欢迎页（偏好可开启欢迎面板：最近文件 + 快捷入口）。

**WM-006 (P1) 空白文档占位**
空文档**不显示任何占位文案**，仅显示光标。此条记录决策以防实现者自行添加。

**WM-007 (P2) 斜杠命令**
不实现，记录为非目标以避免范围蔓延。

## 8. 导入与导出

### 8.1 导出（菜单 文件 → 导出）

**EX-001 (P0) HTML**
两种变体：`HTML`（包含主题样式，内联 CSS，可离线查看）与 `HTML（不含样式）`（纯语义 HTML 片段，供粘贴到 CMS）。内容：标题带锚点 id；TOC 生成；脚注聚合到末尾；代码块带 `<pre><code class="language-x">` 与内联高亮 span（可选纯文本）；公式输出为 SVG 内联（默认）或 MathML（可选）或保留 TeX 用 `$$` 包裹（可选，供 MathJax 页面）；图表输出 SVG；图片路径：保持相对路径 / 转为绝对 `file://` / 内嵌 base64（选项）；Front Matter 不输出；GitHub Alerts 输出带类名的 div；仅输出文档实际用到的样式。可在偏好中设置"导出 HTML 时附加的头部 HTML / 尾部 HTML / 自定义 CSS"。

**EX-002 (P0) PDF**
自研分页：按页面设置（纸张 A4/Letter/A3/A5/Legal/自定义、方向、四边边距、页眉页脚模板支持 `{{title}} {{page}} {{pages}} {{date}}`）对布局树分页；避免标题与下文分离（keep-with-next）、避免孤行寡行、表头跨页重复、代码块允许跨页、图片过大缩放至页内。输出使用 krilla：真实可选文本、嵌入字体子集、超链接可点击、内部链接跳转、**书签（大纲）来自标题**、元数据（标题、作者取自 Front Matter）。选项：使用当前主题颜色/亮色主题、绘制页面背景、导出后打开。打印：1.0 实现为"导出 PDF 并交给系统打印对话框"。

**EX-003 (P1) 图片**

**EX-004 (P1) Pandoc 桥接**
检测 `pandoc` 可执行文件（PATH 或偏好指定路径；未安装时导出菜单置灰并显示安装引导链接 pandoc.org/installing）。格式：Word `.docx`、OpenOffice `.odt`、RTF、EPUB、LaTeX `.tex`、Media Wiki、reStructuredText、Textile、OPML、Org-mode。执行：先用内部序列化把文档规范化为 Pandoc Markdown（保留 Front Matter、公式 `$$`、图片路径解析为绝对路径、Mermaid 预渲染为 PNG 嵌入），再 `pandoc -f gfm+... -t <fmt> --standalone`。偏好可添加自定义导出项：命令行模板（`pandoc $input -o $output --reference-doc ref.docx`）。显示进度与错误输出。

**EX-005 (P1) 导出设置页**
偏好 → 导出：每种格式的独立设置（PDF 页面设置、HTML 附加内容、图片倍率、Pandoc 参数）、"导出时使用的主题"、"导出到源文件同目录并同名"快捷导出（无默认快捷键，可自定义）。可以新增/删除/重排导出项。源码模式下导出亦可用。

**EX-006 (P0) 复制为 HTML**

[回填 2026-10-13] 导出实现细节：(1) PDF 与图片导出复用编辑器实时视图布局（光标置于文档外，全部标记隐藏），按页面内容宽度排版，布局像素按 0.75 pt/px 缩放（与 CSS 一致）；脚注定义统一移到文末短分隔线之下；HTML 注释不出现在 PDF/图片中；拼写波浪线不输出。(2) 未勾选"绘制页面背景"时页面为白色，若导出主题为深色主题则改用 Paper 主题，避免浅色文字落在白纸上。(3) 分页规则：块在页尾放不下时整体移到下一页；可分行的块（段落、代码块、表格、列表项）按行边界拆分，拆分时不留单行孤行/寡行；标题与其后第一行同页；表格跨页时在下一页顶部重复表头；高于一页的图片按页高等比缩小；高于一页且不可分的块按页高截断。(4) 页眉页脚模板居中绘制于上下边距中线，`{{date}}` 为导出当日（UTC，YYYY-MM-DD）。(5) 打印：导出 PDF 到临时目录后，Windows 以系统"打印"动作交给默认 PDF 程序，macOS 用"预览"打开，Linux 用默认程序打开。(6) 导出偏好键为 `export.*`（主题、导出后打开、纸张/方向/自定义尺寸/四边边距（毫米）/页眉/页脚/背景、HTML 图片路径/公式输出/高亮/附加头尾/自定义 CSS/软换行、图片倍率与分页、Pandoc 路径与附加参数、自定义导出项 `export.custom`：每项 `名称|扩展名|命令模板`，模板支持 `$input $output $outputDir`），完整列表见 `docs/preferences.md`。(7) Pandoc 未安装时 Pandoc 格式置灰，导出子菜单提供"获取 Pandoc…"打开 pandoc.org/installing。(8) 公式输出可选 SVG（默认）、MathML（表现标记，附 TeX 注释）或 TeX。(9) 右键公式块/图表：复制为 SVG、复制为 PNG、导出图片（按扩展名 `.png`/`.svg`）。

## 11. 命令系统、CLI 与自动化

**CM-001 (P0) 命令注册表**
每个命令：`id`（点分小写）、`title`（i18n key）、`category`、`params schema`（serde JSON Schema）、`enabled(ctx) -> bool`、`checked(ctx) -> Option<bool>`、`run(ctx, params) -> Result<Outcome>`、`undo_group`。宏录制（P2）记录命令序列。`cargo xtask commands` 导出 `docs/commands.md`（含参数与说明），该文档是 AI 代理驱动应用的接口合同。命令总数预计 150 至 200 个。

**CM-002 (P1) CLI** `inkra-cli`
```
inkra-cli convert in.md out.pdf|out.html|out.png|out.docx   # docx 等需 pandoc
inkra-cli inspect in.md [--json]            # AST / 标题 / 链接 / 图片 / 字数统计
inkra-cli lint in.md                        # 结构问题：断链、缺图、未闭合围栏
inkra-cli fmt in.md [--write]               # 规范化（MD-092 规则）
inkra-cli run in.md --cmd 'format.bold' --cmd 'select.heading={"index":1}' --save out.md
inkra-cli theme import style.css            # TH-005
inkra-cli commands                          # 列出命令
```
退出码：0 成功、1 参数错误、2 文件错误、3 转换错误。

**CM-003 (P2) 控制通道与 MCP**
`inkra --control <port>` 开启本地 JSON-RPC（loopback，随机密钥文件授权）：`execute`、`batch`、`inspect_document`、`screenshot`、`click`、`key`、`open`、`save`。`inkra-cli mcp` 把命令包装为 MCP 工具，使 AI 代理能驱动编辑器。

**CM-004 (P1) 命令行参数**
`inkra [files...|folder]`、`--new`、`--source-mode`、`--theme <name>`、`--config <path>`、`--version`、`--measure-startup`、`--no-session`。
[回填 2026-10-12] `--measure-startup`：在第一帧呈现后（第二帧开始时）向 stdout 打印 `startup_ms=<毫秒>` 并写日志，然后退出，便于脚本与 CI 测量；计时起点为 `main()` 入口。`--config <dir>` 把 `<dir>/config`、`<dir>/data`、`<dir>/cache` 作为配置、数据、缓存目录（便于便携与测试）。另支持 `--help`。

## 12. 非功能需求

**NF-001 (P0) 性能** 第 2.5 节预算全部满足；CI 中运行基准（criterion）并对 p95 回归 > 20% 报警。
**NF-002 (P0) 稳定性** 任何命令的 panic 被捕获（`catch_unwind` 在命令边界），记录日志并显示"操作失败"提示，文档内容不丢失；解析器对任意输入不 panic（proptest 模糊测试，含 1 MB 随机字节与 CommonMark 规范全部例子）。
**NF-003 (P0) 数据安全** 原子写入；恢复目录；永不在未经用户确认时覆盖外部修改；删除走回收站。
**NF-004 (P0) 隐私** 无遥测、无网络请求（除：用户触发的网络图片加载、更新检查、图片上传）。网络图片加载可全局关闭。
**NF-005 (P1) 安全** 不执行文档内任何脚本；`<iframe>`/`<script>` 不加载；链接打开前显示完整 URL（`javascript:`、`file:` 指向可执行文件时阻止）；Pandoc/mmdc/图片上传命令路径由用户显式配置，参数转义防注入；导出 HTML 对用户内容转义。
**NF-006 (P0) 平台** Windows 10 1809+（x64、arm64，MSI + 便携 zip，代码签名 P2）；macOS 12+（universal dmg，签名公证 P2，Finder 双击与 "Open With"）；Linux（AppImage、deb、rpm、Flatpak、tar.gz；X11 与 Wayland，Wayland 下拖放文件受 winit 限制时自动回退 XWayland，并提供 `INKRA_WAYLAND=1` 强制原生 Wayland）；文件关联 `.md` 等；三平台安装包与可执行文件均嵌入附录 C 的应用图标（UI-050）。
**NF-007 (P1) 国际化** 界面文案全部走 fluent；1.0 提供简体中文、英文；资源结构预留其他语言（繁中、日、韩、法、德、西、葡、俄等），社区可贡献。
**NF-008 (P1) 日志** `<data_dir>/logs/inkra.log`，滚动 3 份、16 MiB 上限，`RUST_LOG` 覆盖；不记录文档内容。
**NF-009 (P1) 更新** 检查 GitHub Releases 的最新版本，提示下载链接；不自动安装。
**NF-010 (P0) 可测试性** 所有 UI 可通过 `egui_kittest` 无头驱动与截图；`ui_shot` example 可从命令行渲染任意文档为 PNG 用于回归与文档配图。
**NF-011 (P1) 资源许可** 所有字体 OFL、界面图标 MIT/Apache、emoji 数据 MIT；应用图标为项目原创，随代码以 MIT OR Apache-2.0 发布（附录 C）；`cargo about` 生成 NOTICE；禁止拷贝任何第三方商业软件的资源（图标、样式、文案）。

### D.2 图标设计

图标由三个元素组成：一道书法笔触的小写字母 `i`（品牌首字母，同时象征一笔刻痕，呼应中文名"墨刻"）、`i` 上方的圆形墨点、右侧一根珊瑚色竖线（文本光标，表达"编辑"）。背景为暖白纸色的 Apple 风格连续圆角 squircle。设计意图：在 16 px 下仍可辨识的两色极简图形，不依赖文字或渐变。

### D.5 生成与规则

- 全部派生文件由 `tools/build_icons.py` 从母版生成，禁止手工编辑派生文件；修改设计时只替换母版并重新运行脚本。
- squircle 使用超椭圆 `|x|^5 + |y|^5 = 1`，圆角比例 22.37%，与 macOS 图标网格一致。
- 不得在图标上叠加文字、徽标、版本号或平台标识；不得拉伸、旋转、重新着色（单色与暗色变体除外）。
- 最小使用尺寸 16 px；低于 24 px 时优先使用 `mono/` 字形。

## 附录 D. 开放问题（实现过程中需决策并回填）

1. 内置 CJK 字体子集的体积（约 8 至 15 MB）与依赖系统字体之间的取舍；建议 1.0 依赖系统字体并在缺失时提示下载。 [回填 2026-10-12] 采纳建议：依赖系统字体。M0 起按平台已知路径加载系统 CJK 字体（Windows `msyh.ttc`，macOS `PingFang.ttc`，Linux Noto Sans CJK / 文泉驿）作为回退，TH-006 完整回退链在 M4 外观偏好中实现。
2. 数学排版自研的工作量评估：若 M5 期限内无法覆盖 200 个公式语料的 90%，降级方案为调用外部 `tectonic`/`latex` 渲染为 SVG（P2 开关）。
3. egui 的文本编辑能力有限（无富文本光标映射），编辑区需完全自研文本输入与光标系统，仅复用 egui 的事件与绘制；这是 M2/M3 最大风险，需在 M1 结束前做原型验证（10 万字文档实时渲染输入延迟）。
4. Windows 一体化标题栏（自绘）与系统 Snap 布局、Aero 拖拽的兼容性。
5. 侧边栏展开状态与文档光标位置的持久化粒度（按根目录一个文件，还是集中在会话文件）：建议集中在会话文件，避免污染用户文件夹。
